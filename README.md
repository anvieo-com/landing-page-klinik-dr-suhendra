# Landing Page Klinik dr. Suhendra

Official landing page & web portal untuk **Klinik dr. Suhendra**, jaringan klinik pratama & rawat inap 24 jam dengan 6 cabang strategis di wilayah Bogor.

## ✨ Fitur Utama

- **Beranda Interaktif**: Hero section dinamis, statistik pencapaian 500.000+ pasien terlayani & 7 ruang rawat inap, keunggulan layanan, ulasan pasien, serta hotline darurat IGD 24 jam.
- **Peta Jaringan Klinik Interaktif (OSM & Leaflet)**: Visualisasi seluruh 6 cabang klinik pada OpenStreetMap lengkap dengan custom pin point dan drawer detail cabang interaktif (foto klinik, dokter bertugas, fasilitas, jam operasional, direct WhatsApp, & rute Google Maps).
- **Portal Warta & Kegiatan Medis (`/kegiatan`)**: Tampilan portal berita modern dengan tab kategori, pencarian artikel, headline berita utama, katalog berita dengan paginasi, serta sticky sidebar berita terkini.
- **Katalog Layanan Medis Lengkap (`/layanan`)**: Informasi poli umum, poli gigi, IGD 24 jam, persalinan, laboratorium, farmasi, serta rawat inap.
- **Jadwal Dokter (`/jadwal`)**: Jadwal praktik dokter umum dan spesialis per cabang dengan filter tanggal dan poli.
- **Profil & Nilai Klinik (`/tentang`)**: Visi, misi, sejarah perjalanan 10 tahun melayani, dan komitmen kesehatan keluarga.
- **Desain Responsif & Modern**: Built with Next.js App Router, Tailwind CSS, serta Lucide Icons.

## 🚀 Menjalankan Project

### Prasyarat
- Node.js 18+ atau 20+
- npm, yarn, pnpm, atau bun

### Instalasi
```bash
# Clone repository
git clone https://github.com/anvieo-com/landing-page-klinik-dr-suhendra.git
cd landing-page-klinik-dr-suhendra

# Install dependencies
npm install
```

### Development Server
```bash
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

### Production Build
```bash
npm run build
npm start
```
